# Elite CS66 A1 stand

Visual-only support, four casters and two controller cabinets from the hash-locked A1 STEP. Two fixed CS66 mount frames preserve source assembly poses. Arms and the 120 cm table are reused as separate catalog assets.

See `provenance/step_derivation.json` for occurrence mapping, source units, coordinate transform and table position. No dynamics, collision or calibration was inferred.
